상태 변화

강우 중에는 시설 상태가 순차 또는 동시다발적으로 변하고, 이 변화가 배수 흐름과 판단 기준에 영향을 줍니다.

기존 점검 방식의 한계

공백

유지관리에는 필요

정기 점검과 청소는 시설 유지관리의 기본 흐름입니다. 문제는 이 방식 자체가 아니라 강우 중 빠르게 바뀌는 현재 상태를 즉시 반영하기 어렵다는 점입니다.

현재 상태 판단에는 공백

  • 점검 이후 상태 변화 발생 가능
  • 신고 전까지 발견이 늦어질 수 있음
  • 시설별 우선순위를 자동으로 정리하기 어려움
  • 이미지 근거와 센서 근거가 분리될 수 있음

내부 점수
영상 막힘 점수 = 막힌비율 × 탐지 신뢰도
센서 정체 점수 = 수위 × (1 - 유속)
최종 위험 점수 = 영상 45% + 센서 45% + 수위 10%

최종 위험 점수는 실제 침수 확률이 아니라, 우수주의보 내부 위험도 분류를 위한 계산 점수입니다.
