# SmartDrain Design Direction

This file guides style preview generation. It does not select the final style.

## Presentation Character

SmartDrain should feel like a technical infrastructure monitoring project, not a generic AI pitch deck.

Preferred qualities:

- urban infrastructure
- monitoring dashboard
- engineering report
- credible MVP
- traceable system flow
- clear section hierarchy

Avoid:

- generic purple AI gradients
- overly decorative startup pitch visuals
- copying the old SmartDrain PPT layout
- copying the Fingtron design
- making the deck look like a marketing landing page
- showing fake production operations

## Style Preview Requirements

Generate three distinct style previews before final deck generation.

Each preview should look like a real first slide for this deck. It should not show internal labels like "Option A", "template", "preview", or file names on the slide.

Each preview should imply how the design can handle:

- technical flow diagrams
- data tables
- dashboard screenshots
- AI pipeline diagrams
- DB/ERD explanation
- operations consideration
- demo scenario

## Useful Visual Motifs

- drain grid / street-water pattern
- map grid or infrastructure grid
- status colors: good, caution, danger, unknown
- pipeline arrows
- callback/event pulses
- database blocks
- monitoring console indicators

## Color Guidance

Do not lock the final palette yet. For previews, explore three genuinely different directions:

1. restrained technical report
2. dark control-room dashboard
3. field infrastructure / operations notebook

Maintain sufficient contrast and avoid one-note palettes.

## Typography Guidance

Use distinctive but readable fonts. Korean text must remain legible. Do not use tiny type to force content onto one slide.

## Motion Guidance

Use subtle CSS-only motion in previews:

- title reveal
- flow pulse
- status indicator blink
- staggered diagram entry

Avoid excessive motion that distracts from technical explanation.
